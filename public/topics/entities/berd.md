# Berd

Berd is Block's Apache-2.0 desktop workspace for working with AI agents. It sits above harnesses such as goose, Claude Code, and Codex rather than replacing them: a Tauri 2 + React 19 app talks to a bundled goose sidecar over the Agent Client Protocol, keeps session history on device, and is meant as the single-player starting point before Buzz's multiplayer rooms.
