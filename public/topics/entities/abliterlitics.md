# Abliterlitics

Abliterlitics is Nathan Sapwell's open-source forensics toolkit for comparing abliteration techniques on the same base model. It measures weight-level edits, KL divergence, capability benches, and HarmBench rather than taking “lossless” or “uncensored” claims at face value.
