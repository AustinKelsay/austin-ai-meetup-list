# TurboFieldfare

TurboFieldfare is a Swift + Metal inference runtime that runs the instruction-tuned Gemma 4 26B-A4B checkpoint on Apple Silicon by keeping the shared core and KV cache in RAM and streaming routed MoE experts from SSD.
