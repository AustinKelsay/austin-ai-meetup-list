# Cloudflare OS

Cloudflare OS is an open-source agent workspace on Cloudflare Workers that pairs company-context chat with sandboxed personal apps called Gadgets, using Gatekeepers to broker external services—framed by Kenton Varda as a Sandstorm remake for the AI era.
