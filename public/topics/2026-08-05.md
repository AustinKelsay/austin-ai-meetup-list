### Agent Infrastructure
- **Uncle Bob's senior job is constraints, not reading agent code** - Uncle Bob's current strategy is not to read agent-written code at all. He surrounds the [[Coding Agents|agents]] with extreme constraints and unit tests, and treats that harness as the new senior craft.
  Post: https://x.com/unclebobmartin/status/2080257779395154409

- **Cloudflare OS turns Sandstorm's grain model into agent-safe Gadgets** - Kenton Varda open-sourced [[Cloudflare OS]] on Workers: a personal-app "vibe coding" workspace where each document/app runs as its own sandboxed Gadget (Sandstorm Grain), the platform owns ACL, and Gatekeepers broker external APIs. Treat the "AI cannot introduce a significant security bug" claim as the vendor pitch—the durable bet is per-instance isolation plus promptable per-user forks of the code.
  Repo: https://github.com/cloudflare/cloudflare-os
  Source: https://blog.cloudflare.com/cloudflare-os/
  Post: https://x.com/KentonVarda/status/2084990137180590572

- **Prime Agent is an open RLM coding harness that can rewrite itself** - [[Prime Agent]] is Prime Intellect's open-source coding / long-horizon agent: a persistent IPython REPL where context lives as a variable, sub-agents are `await rlm(...)` calls, and a Continual Harness lets the agent CRUD its own prompts, skills, memory, and sub-agents. Author-reported Opus 5 runs hit 95.5% RHAE Best@1 on [[AI Benchmarks & Evals|ARC-AGI-3]]—just above the 95.4% human expert baseline. For an [[Recursive Language Models|RLM]] 101, start with Alex Zhang's explainer, then the paper, then Prime Intellect's own RLM writeup.
  Repo: https://github.com/PrimeIntellect-ai/prime-agent
  Source: https://www.primeintellect.ai/blog/prime-agent
  Post: https://x.com/PrimeIntellect/status/2085086999267144083
  Post: https://x.com/MTSlive/status/2085098975707996558
  Source: https://alexzhang13.github.io/blog/2025/rlm/
  Source: https://arxiv.org/abs/2512.24601
  Source: https://www.primeintellect.ai/blog/rlm
  Source: https://arcprize.org/scorecards/2af780b4-f2a1-43e9-a794-b23da3cd3f9f

- **Meta ships Muse Code with co-trained Muse Spark 1.2** - [[Meta]]'s [[Meta Muse|Muse Code]] beta is a terminal [[Coding Agents|coding agent]] for large repos: persistent background agents, parallel worktree sub-agents, and a local event log that resumes after crashes. It ships with Muse Spark 1.2, which Meta says was co-trained on the harness—including a vendor case study of 1,000+ tool calls over 24 hours on Hopper kernels.
  Source: https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2

- **TurboFieldfare runs Gemma 4 26B-A4B in ~2 GB on Apple Silicon** - [[TurboFieldfare]] is a Swift + Metal runtime that keeps [[Gemma|Gemma 4]] 26B-A4B's shared core and KV cache in RAM and streams only the routed experts from SSD—author claim ~2 GB resident against a ~14.3 GB installed model. Measured decode is about 5–6 tok/s on an 8 GB M2 Air and 31–35 on an M5 Pro; requires macOS 26 / Metal 4, and the runtime is Gemma-specific rather than a general llama.cpp wrapper.
  Repo: https://github.com/drumih/turbo-fieldfare

### Security

- **Shai-Hulud hits keyv and 2B monthly npm installs** - After May's Mini Shai-Hulud wave, attackers compromised the GitHub account behind `keyv` and its cacheable family, then wormed credential stealers across hundreds of packages totaling over 2 billion monthly installs. Poisoned releases shipped with valid GitHub Actions provenance, so "signed" no longer means "safe."
