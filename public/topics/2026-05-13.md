### Agent Infrastructure
- **Matt Pocock skills turned prompts into infrastructure** - The viral bit is not the repo itself; it is that engineering taste, review loops, TDD, issue triage, and planning rituals are becoming portable [[Coding Agents]] behavior.
  Repo: https://github.com/mattpocock/skills
  Source: https://agentconn.com/agents/mattpocock-skills/
  Source: https://llmbase.ai/skills/mattpocock/
- **Claude as bitcoin wallet forensics** - A lost-wallet story became a weirdly good agent demo: dump the old computer context in, have Claude trace files, debug btcrecover, and turn digital archaeology into recovered keys.
  Post: https://x.com/cprkrn/status/2054586810475364536
  Source: https://news.bitcoin.com/bitcoiner-dumps-old-computer-files-into-claude-ai-recovers-5-btc-lost-since-2015/
  Source: https://beincrypto.com/bitcoin-wallet-claude-ai-recovery/
- **Sandcastle** - TypeScript runner for sending [[Coding Agents]] into isolated worktrees and collecting the results. Fits the [[Agent Infrastructure]] thread because it makes agent work easier to isolate and review.
  Repo: https://github.com/mattpocock/sandcastle
  Source: https://www.sourcepulse.org/projects/27307520
- **Amnesic personal OS** - Fully local, private OS concept that boots from a USB stick and leaves no trace on the host machine.
  Post: https://x.com/nichxbt/status/2046647915343741391
- **Agents as fields** - Attio-style AI attributes put agents inside the workflow instead of beside it. Another [[Agent Infrastructure]] angle: agents become part of the data surface.
  Post: https://x.com/rrhoover/status/2048366028850163752
  Source: https://dribbble.com/shots/25870869-Attio-AI-Attributes
- **Isaac Sim for beginners** - NVIDIA's robotics simulator pitch: prototype the chassis, wheels, sensors, and environment before touching hardware.
  Post: https://x.com/_vmlops/status/2048594851374243967
  Source: https://developer.nvidia.com/isaac/sim
- **Claude Managed Agents learn between runs** - Anthropic is moving agent memory, outcomes, orchestration, and webhooks into the managed platform layer. "Dreaming" is still preview, but the direction is clear: durable agents are becoming hosted product surface, not just your own loop around an API.
  Source: https://claude.com/blog/new-in-claude-managed-agents
  Source: https://claude.com/code-with-claude/session/sf-memory-and-dreaming-for-self-learning-agents
  Source: https://www.anthropic.com/news/higher-limits-spacex
- **The agent harness belongs outside the sandbox** - Mendral's backend-harness argument is a clean [[Agent Infrastructure]] split: keep credentials, memory, and durable execution outside the disposable workspace, then reach into the sandbox over RPC.
  Source: https://www.mendral.com/blog/agent-harness-belongs-outside-sandbox
- **Dumb AI loops die in production** - Rohit's agent-systems writeup is the sober version of the loop hype: building, memory, harness, and orchestration all become product risk once state, auth, and unattended actions enter the chat.
  Source: https://x.com/i/article/2050613084558094336
  Post: https://x.com/rohit4verse/status/2050968031493550202

  Post: https://x.com/anthonyronning/status/2053823121975542061
- **Gemma 4 app surface** - The follow-up question: how fast do the weights become useful across AI Studio, AI Edge Gallery, Ollama, LM Studio, llama.cpp, and now MTP drafters that promise up to 3x faster output.
  Source: https://deepmind.google/models/gemma/

  Post: https://x.com/googledevs/status/2051700498328346945
- **GPT-5.5 Instant becomes the default** - The default ChatGPT and `chat-latest` model moved to GPT-5.5 Instant. Not the flashiest story, but default-model quality is the floor every prototype, workflow, and casual user suddenly inherits.
  Source: https://openai.com/index/gpt-5-5-instant/
  Source: https://openai.com/index/gpt-5-5-instant-system-card/
- **Vibe maths solves an Erdős problem** - The notable bit is not "ChatGPT did math." It is an amateur prompt surfacing a proof route experts say humans had missed, with the human work shifting to interpretation and compression.
  Source: https://www.scientificamerican.com/article/amateur-armed-with-chatgpt-vibe-maths-a-60-year-old-problem/
  Source: https://news.ycombinator.com/item?id=47903126
- **ProgramBench says agents still cannot rebuild software** - Given only binaries and docs, agents have to recreate full programs like `jq`, `ripgrep`, FFmpeg, and SQLite from scratch. GPT-5.5 xhigh tops the leaderboard at 0.5% fully solved, which is a useful cold shower for whole-codebase autonomy.
  Source: https://programbench.com/
  Paper: https://arxiv.org/abs/2511.00079
  Repo: https://github.com/ProgramBench/ProgramBench
- **Talkie tests vintage-model generalization** - A 13B model trained only on pre-1931 text is a cleaner probe for what LMs learn from language versus the modern web. The fun question is whether scale lets a model learn post-cutoff skills like code from examples alone.
  Source: https://talkie-lm.com/introducing-talkie
  Post: https://x.com/status_effects/status/2048878495539843211
- **Red/blue button model behavior** - Jan Kulveit's red/blue button plots are a compact moral-decision probe: same dilemma, different models and reasoning settings, visibly different button preferences.
  Post: https://x.com/jankulveit/status/2048808080188608953
