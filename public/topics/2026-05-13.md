### Agent Infrastructure
- **Sandcastle** - TypeScript runner for sending coding agents into isolated worktrees and collecting the results. Fits the [[Agent Infrastructure]] thread because it makes agent work easier to isolate and review.
  Repo: https://github.com/mattpocock/sandcastle
  Source: https://www.sourcepulse.org/projects/27307520
- **Amnesic personal OS** - Fully local, private OS concept that boots from a USB stick and leaves no trace on the host machine.
  Post: https://x.com/nichxbt/status/2046647915343741391
- **Agents as fields** - Attio-style AI attributes put agents inside the workflow instead of beside it. Another [[Agent Infrastructure]] angle: agents become part of the data surface.
  Post: https://x.com/rrhoover/status/2048366028850163752
  Source: https://dribbble.com/shots/25870869-Attio-AI-Attributes
- **Isaac Sim for beginners** - NVIDIA's robotics simulator pitch: prototype the chassis, wheels, sensors, and environment before touching hardware.
  Post: https://x.com/_vmlops/status/2048594851374243967
  Source: https://developer.nvidia.com/isaac/sim

  Source: https://vercel.com/kb/bulletin/vercel-april-2026-security-incident
  Source: https://labs.cloudsecurityalliance.org/research/csa-research-note-ai-saas-supply-chain-vercel-contextai-2026/
  Post: https://x.com/theo/status/2046767107178676636
- **OpenAI Privacy Filter gets inverted** - A 1.5B Apache-2.0 PII masking model becomes local [[Privacy Tooling]] for names, emails, accounts, addresses, and secrets.
